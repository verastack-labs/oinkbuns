# Design

Stub. This file is written from the built result at the end of plan 3 (art,
audio, feel) and updated in plan 5 (landing page). Until then it only records
what is already fixed so nobody designs against a guess.

## Fixed so far

- Logical game size 1280 by 720, `Scale.FIT`, centred, letterboxed in the
  wall colour.
- Palette (hex), defined once per package and mirrored everywhere:
  peppa pink `#f4a6c6`, peppa red `#e84a5f`, george blue `#4a90e2`,
  wall `#fff1d6`, floor `#d9a066`, outline `#3a2a2a`, bun `#c8803a`,
  cream `#fff8e7`, text `#3a2a2a`, good `#6cc24a`, bad `#e84a5f`,
  sky `#9ad7f5`, grass `#7bc96f`.
- Typeface: Fredoka (SIL Open Font Licence), self-hosted in both packages
  from plan 3. Until then the system sans-serif stands in.
- Style: the show's flat colours and thin dark outlines; side-on heads with
  both eyes on one side; simple limbs. Original vector art only.
